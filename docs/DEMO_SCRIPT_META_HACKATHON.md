# Vibe Architect — Cinematic Demo Shooting Script
### Meta Global AI Developer Hackathon · draft v1 (2026-11-05)

**Format:** ONE **7-second** cinematic cold open (the Kling hero clip) → hard cut straight into **live IDE screen capture** for the body. Cinematic stills (DataQuad diagram, Atlas art) return only as brief inserts and the close. This is deliberately **IDE-forward**: the myth sets the tone in 7s, then real working software carries the demo — judges trust that far more than a video-heavy edit.

**Rubric this is built to win** (judges score these):
- **Demo (25%)** — working, holds up live, *genuinely cool to watch*.
- **Use of Meta AI Tooling (25%)** — beyond basic integration; "capabilities that surprised even us."
- **Impact (30%)** — who benefits, could this be something people use.
- **Technical Depth (20%)** — real craft.
- **+ Most Viral ($20k)** — most X engagement by **Nov 8 11:59 ET**. The viral cut reuses this footage.
